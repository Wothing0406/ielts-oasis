# MEOW-CHA audio sources

Acquired 26 October 2026. All listed sources release these files under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

- **Kenney Vleugels / Kenney — RPG Audio 1.0**:
  https://kenney.nl/assets/rpg-audio
  drawKnife1, knifeSlice, knifeSlice2, bookOpen, bookClose, bookFlip1.
  Original license retained in rpg-CC0.txt.
- **Kenney — Impact Sounds 1.0**:
  https://kenney.nl/assets/impact-sounds
  impactMining_000, impactWood_light_000, impactGlass_heavy_000,
  impactGlass_light_000, impactBell_heavy_000, impactPlate_heavy_000.
  Original license retained in impact-CC0.txt.
- **Tozan — Asianoriental1**:
  https://opengameart.org/content/asianoriental1
  Original asianoriental1_0.ogg, bundled as asianoriental1.ogg without changes.
  The author's page explicitly lists CC0 and describes koto, shakuhachi and
  ensemble strings. This is an Asian-style composition; it is not represented
  as a newly recorded guqin performance.

Physical SFX and main music use these files. Tiny feedback and a quiet wind
layer remain procedural. If a browser cannot decode a file, the existing
procedural audio remains an explicit compatibility fallback.
